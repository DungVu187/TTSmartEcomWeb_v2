# Ma trận API contract

## Checkpoint và quy tắc đếm

Snapshot: 2026-08-13 sau lần quét lại controller cuối cùng và lượt build/test backend thành công.

- Kiểm kê legacy: 201 khai báo handler đã mount. Mỗi khai báo cũng có alias `/api` có hiệu lực, tổng cộng 402 method/URL forms.
- Độ phủ route V2: cả 201 contract method/path của legacy đều đã khai báo. Middleware prefix tạo ra 402 effective URL forms.
- Cả 201 contract đi tới xử lý substantive; explicit `501` và absent đều bằng 0. Năm route trước đây bị hoãn (`scan-invoice`, hai voice query và hai route Zalo OAuth) hiện có implementation qua provider/state boundary.
- `Substantive` không có nghĩa là tương đương về hành vi. Integration test MongoDB biệt lập dùng dữ liệu tổng hợp, protocol Socket.IO và pipeline API đã mở rộng, nhưng chưa có so sánh integration rộng cho mọi collection/endpoint hoặc provider/staging E2E.
- Lượt chạy backend đầy đủ có 332 test: Unit 231, Contract 53, Integration 16 và Security 32. Đây không phải 201 endpoint test; coverage positive theo từng route vẫn được chọn lọc.

## Bằng chứng đối chiếu route

Sổ bằng chứng độc lập nằm tại [ROUTE_RECONCILIATION.md](ROUTE_RECONCILIATION.md).

- Việc liệt kê chỉ đọc 15 router được mount bởi `be/index.js` trong legacy tìm thấy 201 khai báo: users 30, products 35, orders 20, chips 18, chip types 3, carts 6, manages 24, import orders 17, export orders 17, stations 12, histories 4, activity logs 1, Zalo 4, Telegram 6 và voice vocabulary 4. 13 khai báo trong `components/drink.js` chưa mount bị loại.
- V2 có 175 attribute `[Http*]` thô. Mở rộng controller cơ sở inventory dùng chung dưới cả `/iporders` và `/eporders` (+17), cùng route storefront có ràng buộc `update-section1..10` (+9), tạo 201 method/path forms đã chuẩn hóa.
- So sánh method/path đã chuẩn hóa cho thấy 0 contract missing và 0 extra; mỗi form đã khai báo có URL hiệu lực không prefix và có prefix `/api`, tạo 402 form. Điều này chỉ chứng minh độ phủ khai báo; không chứng minh parity của response, persistence, authorization, provider hoặc side effect.

## Hành vi route dùng chung

`ApiPrefixCompatibilityMiddleware` loại bỏ `/api`, nên mọi route V2 đã khai báo đều nhận cả hai dạng URL legacy. Alias có một contract smoke test qua `/api/users/login`; `/api/health/live` và `/api/carts/getCart` được bao phủ ở nơi khác. Điều này chỉ xác minh các ví dụ middleware, không phải toàn bộ 201 alias.
